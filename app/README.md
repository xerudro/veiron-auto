# app

Directorul pentru backend-ul aplicației VEIRONAUTO (PHP, API, logică server).

## Structură
- **config/** – Configurări aplicație, conexiuni DB, email
- **api/** – Endpointuri PHP pentru CRUD și integrare
- **includes/** – Funcții, validări, utilitare partajate
- **admin/** – Backend pentru panoul de administrare

Toate fișierele PHP și logica server-side sunt organizate aici.
