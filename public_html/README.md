# public_html

Acesta este directorul principal pentru frontend-ul aplicației VEIRONAUTO.

## Structură
- **assets/** – CSS, JS, imagini, librării, date JSON
- **admin/** – Interfață și resurse pentru panoul de administrare
- **index-ro.html** – Homepage în limba română
- **index-en.html** – Homepage în limba engleză
- **contact.html** – Pagina de contact

Toate resursele statice și paginile vizibile utilizatorului sunt organizate aici.
