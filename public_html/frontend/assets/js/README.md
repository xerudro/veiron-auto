# js

Scripturi JavaScript pentru interactivitate și logica aplicației.

## Subfoldere
- **pages/** – Scripturi specifice pentru pagini (ex: formular-rezervare.js, slider.js)
- **core/** – Scripturi de bază (scripts.js)
- **components/** – Scripturi pentru componente reutilizabile (booking-init.js, email-service.js, etc.)
- **i18n/** – Scripturi pentru internaționalizare

## Fișiere principale
- app.js, contact-harta.js, contact-locator.js

Organizează scripturile pe funcționalitate și pagină.
