**Car Rental Platform with Multi-language Support**

**Technology Stack:** HTML5, UIkit, Vanilla JavaScript, lightGallery, Swiper, PHP, MariaDB, PHPMailer  
**Languages:** Romanian (RON), English (EUR)  
**Current Progress:** 14/161 tasks completed (8.7%)  
**Last Updated:** July 2025

## 1. Product Overview

VEIRONAUTO is a modern car rental platform designed for Romanian and European markets, offering seamless multi-language support with Romanian (RON) and English (EUR) versions. The platform provides a complete booking experience from car selection to confirmation, featuring responsive design, advanced filtering, and integrated payment processing.

The platform solves the need for efficient car rental services by providing users with an intuitive interface to browse, filter, and book vehicles while offering administrators comprehensive fleet and booking management tools. Target users include individual customers and corporate clients across Romania and Europe seeking reliable car rental services.

## 2. Core Features

### 2.1 User Roles

| Role | Registration Method | Core Permissions |

### 2.2 Feature Module

The VEIRONAUTO car rental platform consists of the following essential pages:

1. **Home Page**: Hero section with "Simple and Fast" messaging, featured car carousel with 4 vehicles per view, quick booking section with dark car cards
2. **Car Catalog**: Grid display of available vehicles (4 cards per row on desktop), filtering options, detailed car specifications
3. **Booking Process**: Multi-step reservation wizard with car selection, personal details, and confirmation
4. **Contact Page**: Contact form, company information, and location details
5. **Legal Pages**: Terms and conditions, privacy policy (both in Romanian and English)
6. **Admin Panel**: Vehicle management, booking administration, and reporting dashboard

## 3. Core Process

### User Booking Flow
1. **Homepage**: User lands on homepage, views popular cars carousel, clicks "Book Now"
2. **Catalog**: User browses car catalog, applies filters (transmission, class), views car details in lightGallery
3. **Booking Step 1**: User selects preferred car from grid (4 cards/row desktop, responsive mobile)
4. **Booking Step 2**: User enters personal data, selects additional services (GPS, child seats), chooses warranty plan
5. **Booking Step 3**: User reviews booking summary with cost breakdown, confirms details
6. **Booking Step 4**: User receives confirmation, email sent via PHPMailer

### Admin Management Flow
1. **Login**: Admin accesses admin panel with credentials
2. **Dashboard**: Admin views booking statistics, fleet status, recent reservations
3. **Fleet Management**: Admin adds/edits cars, manages pricing, updates availability
4. **Booking Management**: Admin processes reservations, handles customer inquiries, generates reports

## 5. Technical Architecture

### 5.1 Frontend Architecture

- **HTML5**: Semantic markup with proper accessibility attributes
- **UIkit Framework**: Component library for consistent UI elements
- **Vanilla JavaScript**: No heavy frameworks, optimized performance
- **CSS3**: Modern styling with CSS Grid, Flexbox, and custom properties
- **Third-party Libraries**:
  - **lightGallery**: Image gallery with lightbox functionality
  - **Swiper**: Touch-enabled carousel for popular cars

### 5.2 Backend Architecture

- **PHP 7.4+**: Server-side logic without frameworks for optimal performance
- **MariaDB**: Relational database for data persistence
- **PHPMailer**: SMTP email integration for booking confirmations
- **RESTful API**: Clean API endpoints for frontend-backend communication

### 5.3 Database Schema

**Core Tables:**
- `cars`: Vehicle information, pricing tiers (1-3, 4-7, 8-14, 15-30 days), availability, specifications, warranty amounts, insurance options
- `bookings`: Reservation data, customer information, booking status
- `additional_services`: GPS, child seats, and other optional services
- `warranty_plans`: Basic and Premium warranty plan details
- `users`: Administrator accounts for backend management

**Key Relationships:**
- Bookings reference cars and selected services
- Many-to-many relationship between bookings and additional services
- Foreign key constraints ensure data integrity

## 9. Pricing Logic & Business Rules

### 9.1 Dynamic Pricing Structure
Based on client's Excel data, pricing varies by rental duration:
- **1-3 days**: Highest daily rate
- **4-7 days**: ~5-7% discount from 1-3 day rate
- **8-14 days**: ~10-15% discount from 1-3 day rate  
- **15-30 days**: ~15-25% discount from 1-3 day rate

### 9.2 Insurance Options
- **Premium Insurance**: 8€-20€/day + 100€ deposit
- **Full Insurance (Integrala)**: 15€-28€/day + 0€ deposit
- Some vehicles only offer Premium insurance

### 9.3 Additional Costs
- **KM Limit**: 300 km/day included
- **Extra KM**: 0.10€ per km over limit
- **Optional Equipment**: Baby chair, Height booster = 2€/day
- **Standard Equipment**: GPS, Baby Seat, Child Seat = 5€/day
- **Additional Driver**: 15€/rental (first driver included)

## 10. API Specifications

### 10.1 Core API Endpoints

**Car Management**
- `GET /api/cars` - Retrieve all available cars with filters
- `GET /api/cars/{id}` - Get specific car details
- `POST /api/cars` - Add new car (Admin only)
- `PUT /api/cars/{id}` - Update car information (Admin only)
- `DELETE /api/cars/{id}` - Remove car (Admin only)
- `GET /api/cars/pricing/{id}` - Calculate pricing for specific duration

**Booking Management**
- `POST /api/bookings` - Create new booking
- `GET /api/bookings/{id}` - Get booking details
- `PUT /api/bookings/{id}` - Update booking status (Admin only)
- `GET /api/bookings` - List all bookings (Admin only)

**Availability & Pricing**
- `POST /api/availability` - Check car availability for dates
- `POST /api/pricing` - Calculate booking price with services
- `GET /api/services` - Get additional services list
- `GET /api/warranty-plans` - Get warranty plan options

**Contact & Communication**
- `POST /api/contact` - Send contact form message
- `POST /api/newsletter` - Newsletter subscription

```sql
  category ENUM('economy', 'compact', 'standard', 'premium', 'luxury') NOT NULL,

);
```

### 11.2 Booking Model
```sql
CREATE TABLE bookings (
  id INT PRIMARY KEY AUTO_INCREMENT,
  booking_reference VARCHAR(20) UNIQUE NOT NULL,
  car_id INT NOT NULL,
  customer_first_name VARCHAR(50) NOT NULL,
  customer_last_name VARCHAR(50) NOT NULL,
  customer_email VARCHAR(100) NOT NULL,
  customer_phone VARCHAR(20) NOT NULL,
  customer_age INT NOT NULL,
  pickup_date DATETIME NOT NULL,
  return_date DATETIME NOT NULL,
  pickup_location VARCHAR(100) NOT NULL,
  return_location VARCHAR(100) NOT NULL,
  additional_services JSON,
  warranty_plan ENUM('basic', 'premium') DEFAULT 'basic',
  total_price DECIMAL(10,2) NOT NULL,
  currency ENUM('EUR', 'RON') NOT NULL,
  status ENUM('pending', 'confirmed', 'active', 'completed', 'cancelled') DEFAULT 'pending',
  payment_status ENUM('pending', 'paid', 'refunded') DEFAULT 'pending',
  notes TEXT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (car_id) REFERENCES cars(id)
);
```

- **Phone Field**: Country flag dropdown + country code + phone number (replicated from contact page)
- **Privacy Checkbox**: "I have read and agree to the Rental Terms and Conditions"
- **Commercial Info Checkbox**: "I want to receive commercial information from Autonom. More details here"
- **Complete Button**: Orangered background (#FF4500) with white text

**Step 4 - Final Step Specifications:**
- **Car Display**: Dark car card matching site design (#2C2C2C background)
- **Color Scheme**: Orangered accents (#FF4500) for buttons and highlights
- **Summary Layout**: Detailed breakdown with rental days, services, total cost
- **Styling**: Consistent with overall site branding and dark theme

- Email: Valid email format required
