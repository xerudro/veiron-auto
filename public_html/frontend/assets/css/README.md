# css

Stiluri CSS pentru paginile și componentele VEIRONAUTO.

## Subfoldere
- **pages/** – Stiluri specifice pentru pagini (ex: home.css)
- **common/** – Stiluri comune (reset, variabile, utilitare)
- **components/** – Stiluri pentru componente UI (butoane, carduri, etc.)
- **themes/** – Tematizare și skin-uri

## Fișiere principale
- contact-ro.css, quick-booking.css, rezervare-rapida.css, header.css, formular-rezervare.css, hero-section.css

Fiecare subfolder organizează stilurile pe funcționalitate sau pagină.
