# assets

Resurse statice pentru frontend-ul VEIRONAUTO.

## Structură
- **css/** – Stiluri CSS pentru pagini, componente, teme
- **js/** – Scripturi JavaScript pentru interactivitate și logica paginilor
- **images/** – Imagini pentru mașini, UI, iconuri, steaguri
- **libs/** – Librării externe (UIkit, Swiper, lightGallery, etc.)
- **json/** – Date demo și configurări

Toate resursele statice folosite de frontend sunt organizate aici.
