# components (js)

Scripturi JavaScript pentru componente reutilizabile.

- **booking-init.js** – Inițializare și logica pentru booking rapid
- **email-service.js** – Trimitere emailuri din formular
- **booking-form-handler.js** – Validare și procesare formular rezervare
- **booking-data-manager.js** – Gestionare date rezervare

Adaugă aici scripturi pentru componente noi.
