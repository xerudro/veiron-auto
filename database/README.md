# database

Directorul pentru scripturi SQL, migrații și seed data pentru baza de date MariaDB.

## Structură
- **migrations/** – Scripturi de migrare a schemei
- **seed/** – Date de test/demo
- **schema.sql** – Schemă principală a bazei de date

Toate operațiunile de administrare DB și fișierele SQL sunt organizate aici.
