# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability, please report it immediately by emailing [YOUR EMAIL]. Do NOT create public GitHub issues for sensitive security matters.

## Repository Access Control

- Only approved users may access the project.
- All branches require code review and approval before merging.
- No direct pushes to the main branch allowed.
- Sensitive credentials MUST never be committed.
- Use 2-factor authentication for all contributor accounts.

## Dependencies

- All dependencies must be reviewed for security before use.
- Use automated tools to scan for vulnerabilities regularly.

## Client Viewing Procedures

- Client may access designated branches or environments to view work status.
- All client accounts must be pre-approved and monitored.
