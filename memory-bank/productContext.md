# Product Context: VEIRONAUTO

## Product Description
Permite rezervarea rapidă a unei mașini, cu opțiuni de filtrare, plată și suport multi-limbă.

## User Stories
- Ca utilizator, vreau să pot filtra mașinile după clasă și preț.
- Ca utilizator, vreau să pot face o rezervare rapidă, fără cont.
- Ca utilizator, vreau să pot vedea prețurile în RON/EUR.

## Core Features
- Catalog mașini
- Rezervare online
- Plată (simulată/demo)
- Responsive UI

## Current State
Se implementează front-end-ul complet, fără backend/admin.
